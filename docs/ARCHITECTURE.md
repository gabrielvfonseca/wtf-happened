# ARCHITECTURE_OVERVIEW

## SYSTEM_PURPOSE

WTF_HAPPENED IS A PLAIN-ENGLISH "WHAT CHANGED AND WHY" CLI FOR ANY GIT RANGE. IT IS GROUPED BY INTENT, NOT BY FILE. THE TOOL IS FULLY OFFLINE: NO API KEYS, NO NETWORK REQUESTS, AND YOUR CODE NEVER LEAVES YOUR MACHINE.

## COMPONENT_LAYOUT

```
src/
  cli.ts              # ARGUMENT PARSING AND COMMAND DISPATCH
  git.ts              # GIT DATA COLLECTION (LOG, DIFF, MERGE-BASE, BRANCH)
  parse/diff.ts       # UNIFIED DIFF PARSER
  classify/area.ts    # PATH -> AREA CLASSIFICATION
  classify/change.ts  # DIFF/MESSAGE -> CHANGE KIND CLASSIFICATION
  classify/intent.ts  # INTENT CLUSTERING (CHANGE KIND X AREA)
  summarize.ts        # SUMMARY ASSEMBLY AND WARNING DETECTION
  render/terminal.ts  # TERMINAL OUTPUT (COLORED, GROUPED)
  render/markdown.ts  # MARKDOWN OUTPUT FOR PR BODIES
  render/json.ts      # JSON OUTPUT
  render/ansi.ts      # ANSI ESCAPE HELPERS AND TEXT UTILITIES
  types.ts            # SHARED TYPE DEFINITIONS
```

## DATA_FLOW

1. GIT_DATA_COLLECTION: `git log --numstat` AND `git diff` GATHER COMMITS AND FILE CHANGES FOR THE REQUESTED RANGE.
2. DIFF_PARSING: THE UNIFIED DIFF IS SPLIT INTO PER-FILE HUNKS WITH ADDED/REMOVED LINES.
3. AREA_CLASSIFICATION: EACH FILE PATH IS MAPPED TO AN AREA (AUTH, API, DB, UI, TESTS, CI, DEPS, DOCS, CONFIG, STYLES, SCRIPTS, CORE, OTHER) VIA PATH PATTERNS.
4. CHANGE_KIND_CLASSIFICATION: EACH COMMIT AND FILE IS MAPPED TO A CHANGE KIND (FEATURE, FIX, REFACTOR, REMOVE, RENAME, DEPS, PERF, DOCS, TESTS, CI, CONFIG, STYLE, CHORE, UNKNOWN) VIA CONVENTIONAL-COMMIT PARSING AND DIFF SIGNALS.
5. INTENT_CLUSTERING: COMMITS AND FILES ARE GROUPED INTO INTENT CLUSTERS (CHANGE KIND X AREA) AND RANKED BY IMPACT.
6. SUMMARY_RENDERING: CLUSTERS ARE RENDERED AS PLAIN-ENGLISH SENTENCES IN TERMINAL, MARKDOWN, OR JSON FORMAT.

## OFFLINE_ENGINE

THE CLASSIFIER USES HEURISTICS ONLY. THERE IS NO LLM AND NO NETWORK. WHERE COMMIT MESSAGES ARE VAGUE (WIP, TMP, …), THE TOOL DESCRIBES WHAT CHANGED AND FLAGS THE VAGUE MESSAGE RATHER THAN HALLUCINATING A "WHY".

## COMMAND_REFERENCE

- `wtf-happened` — SMART SUMMARY (PR MODE IF ON A BRANCH AHEAD OF ITS BASE, ELSE RECENT LOG)
- `wtf-happened pr [base]` — SUMMARIZE CURRENT BRANCH VS BASE (DEFAULT: ORIGIN/MAIN)
- `wtf-happened since <when>` — EVERYTHING SINCE "2W", "YESTERDAY", OR "2026-10-01"
- `wtf-happened log [n]` — LAST N COMMITS (DEFAULT 10)
- `wtf-happened commit <ref>` — SUMMARIZE A SINGLE COMMIT
