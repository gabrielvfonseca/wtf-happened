# API_REFERENCE

## INSTALLATION

```bash
# GLOBAL INSTALL
npm i -g wtf-happened

# ONE-OFF USAGE
npx wtf-happened
```

## BINARY_NAMES

- `wtf-happened` (PRIMARY)
- `wtf` (ALIAS)

## FLAGS

| FLAG | SHORTHAND | DESCRIPTION |
|------|-----------|-------------|
| `--md` / `--markdown` | N/A | OUTPUT MARKDOWN (PASTE INTO PR BODY) |
| `--json` | N/A | OUTPUT MACHINE-READABLE JSON |
| `--verbose` / `-v` | `-v` | SHOW EVERY COMMIT AND FILE |
| `--limit <n>` | N/A | MAX COMMITS TO CONSIDER (DEFAULT 100) |
| `--no-color` | N/A | DISABLE COLORS (ALSO HONORS NO_COLOR ENV) |
| `--help` / `-h` | `-h` | SHOW HELP |
| `--version` | N/A | SHOW VERSION |

## COMMAND_EXAMPLES

```bash
# SMART DEFAULT SUMMARY
wtf-happened

# PR TRIAGE MODE
wtf-happened pr origin/main --md > pr-body.md

# COMING-BACK-TO-REPO MODE
wtf-happened since "2 weeks ago"

# LAST N COMMITS
wtf-happened log 20 --json

# SINGLE COMMIT DEEP-DIVE
wtf-happened commit HEAD~3
```

## OUTPUT_FORMATS

### TERMINAL (DEFAULT)

COLORED, GROUPED OUTPUT SHOWING INTENT CLUSTERS WITH ICONS, COMMIT COUNTS, AND +/- LINE DELTAS. HONORS `NO_COLOR` ENVIRONMENT VARIABLE.

### MARKDOWN (`--md`)

MARKDOWN OUTPUT READY TO PASTE INTO A PR OR MR DESCRIPTION. INCLUDES CLUSTER HEADERS, COMMIT LISTS WITH SHORT HASHES, AND WATCH-OUT SECTIONS.

### JSON (`--json`)

MACHINE-READABLE JSON REPRESENTING THE FULL `SUMMARY` OBJECT: MODE, RANGE, COMMIT COUNT, AUTHOR COUNT, TOTAL ADDITIONS/DELETIONS, CLUSTERS, WARNINGS, AND COMMIT COUNT BY CHANGE KIND.

## ENVIRONMENT_VARIABLES

| VARIABLE | EFFECT |
|----------|--------|
| `NO_COLOR` | DISABLES ANSI COLOR OUTPUT WHEN SET TO ANY VALUE |
| `FORCE_COLOR` | SET TO `"0"` TO DISABLE COLORS |

## TYPE_DEFINITIONS

THE `SUMMARY` TYPE INCLUDES: MODE ("PR" | "SINCE" | "LOG" | "COMMIT"), RANGE, COMMIT_COUNT, AUTHOR_COUNT, DATE_RANGE, AUTHORS, TOTAL_ADDITIONS, TOTAL_DELETIONS, CLUSTERS, WARNINGS, COMMIT_COUNT_BY_CHANGE.

EACH `INTENT_CLUSTER` INCLUDES: ID, CHANGE, AREA, TITLE, FILES, COMMITS, ADDITIONS, DELETIONS, SIGNALS.
